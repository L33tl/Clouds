# **AZURE**

## 1. **Azure Data Factory** (Application Services)
- Используется для интеграции и оркестрации данных в облаке Azure.

## 2. **Azure Database for PostgreSQL** (Database)
- Используется для развертывания и управления базами данных PostgreSQL в облаке Azure.

## 3. **Azure Databricks** (Analytics)
- Используется для обработки и анализа данных с использованием Apache Spark.

## 4. **Azure Redis Cache** (Storage & Content Delivery)
- Используется для кеширования данных с помощью Redis в облаке Azure.

## 5. **Azure CDN** (Storage & Content Delivery)
- Используется для доставки контента через сеть доставки контента (CDN).

## 6. **Azure Container Instances** (Compute)
- Используется для развертывания контейнеров в облаке Azure.

## 7. **Machine Learning Studio** (Artificial Intelligence)
- Используется для разработки и развертывания моделей машинного обучения.

## 8. **VPN Gateway** (Networking)
- Используется для создания и управления VPN-сетями в облаке Azure.

## 9. **Traffic Manager** (Networking)
- Используется для управления трафиком в облаке Azure, включая маршрутизацию запросов и балансировку нагрузки.

## 10. **Azure Firewall** (Networking)
- Используется для защиты сети с помощью фаервола в облаке Azure.

## 11. **Notification Hubs** (Mobile Services)
- Используется для отправки уведомлений в мобильные приложения.

## 12. **Power BI Embedded** (Analytics)
- Используется для встраивания отчетов и аналитики Power BI в приложения.
